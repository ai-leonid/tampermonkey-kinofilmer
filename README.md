
# Кинопоиск плееры для просмотра фильмов

> Выпадающая вкладка на странице кинопоиска для бесплатного просмотра


## Установка
1. Установить расширение для браузера [Tampermonkey](https://www.tampermonkey.net/)

2. Добавить расширение в список из `GitHub` (просто перейти по ссылке и нажать Install): [https://github.com/ai-leonid/kinopoisk-filmer/raw/main/kinopoisk-filmer.user.js](https://github.com/ai-leonid/tampermonkey-mega/raw/main/megaparser.user.js)
