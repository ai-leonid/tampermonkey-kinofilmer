
# Кинопоиск плееры для просмотра фильмов

> Кнопка на странице Kinopoisk и IMDB которая ведёт к плееру для просмотра


## Установка
1. Установить расширение для браузера [Tampermonkey](https://www.tampermonkey.net/)
2. [Включите выполнение userscript’ов и режим разработчика](https://www.tampermonkey.net/faq.php?locale=ru#Q209) в вашем браузере.
3. Добавить расширение в список из `GitHub` (просто перейти по ссылке и нажать Install): [https://github.com/ai-leonid/tampermonkey-kinofilmer/raw/main/kinofilmer.user.js](https://github.com/ai-leonid/tampermonkey-kinofilmer/raw/main/kinofilmer.user.js)
